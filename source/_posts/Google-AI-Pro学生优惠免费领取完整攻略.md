- 可以在某鱼等平台搜索「虚拟信用卡」「开卡服务」

## 验证流程

**Step 4：获取验证链接（关键步骤）**

进入验证资格页面后，你会看到：

- **页面标题**：大学在校生可免费使用 Google AI Pro 中的 Gemini，优惠期 1 年
- **原价**：US$19.99/月
- **优惠价**：畅享 12 个月，只需 US$0/月

{% note success flat %}
**关键操作**：
1. 找到 **「验证资格条件」** 按钮
2. ⚠️ **不要直接点击！**
3. **右键点击**该按钮
4. 选择 **「复制链接地址」**
{% endnote %}

复制的链接格式类似：

```
https://services.sheerid.com/verify/67c8c14f5f17a83b745e3f82/?verificationId=695f0be660d4745b471ed587
```

{% note info flat %}
**提示**：如果提示需要美国 IP，请使用指纹浏览器（安卓指纹）或安卓真机/模拟器获取链接。
{% endnote %}

**Step 5：使用 1Key 进行验证**

访问 1Key 官网：`https://batch.1key.me/`

| 步骤 | 操作 |
|------|------|
| 1 | 进入 1Key 网站 |
| 2 | 在 Input 区域选择 **「Google Student」** 类型 |
| 3 | 将刚才复制的链接粘贴到输入框中 |
| 4 | 完成 hCaptcha 人机验证（勾选 "I am human"） |
| 5 | 点击 **「Start Verification」** 开始验证 |

等待验证结果：
- 验证中：通常需要几秒到几分钟
- 成功提示：Verification completed successfully!
- Results 区域：显示 Success 状态

**Step 6：备选方案 - Telegram Bot**

如果 1Key 验证不通过，还有备用方案：使用 **Telegram 频道的 Bot** 进行验证。可以在 Telegram 上搜索相关的学生验证 Bot，按照 Bot 的指引进行验证操作。

**Step 7：回到 Google 完成激活**

验证成功后：

1. 回到刚才的 Google 验证页面
2. **刷新页面**
3. 页面会显示验证已通过
4. 点击继续，进入绑卡页面

**Step 8：绑定支付方式**

在绑卡页面，填写你的 Visa 虚拟卡信息：

| 字段 | 说明 |
|------|------|
| 卡号 | 虚拟卡的卡号 |
| 有效期 | 卡片有效期 |
| CVV | 安全码（卡背面 3 位数字） |
| 账单地址 | 与卡绑定的地址 |

{% note info flat %}
**说明**：虽然显示需要绑卡，但一年内实际是 $0/月。绑定的是虚拟卡，到期后不会扣费成功，可随时取消订阅。
{% endnote %}

绑卡成功后，你的 Google 账号就成功升级为 **Google AI Pro** 了！🎉
